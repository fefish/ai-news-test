### 1、MCP新规范改成无状态核心以降低企业接入门槛 {#event-30158}

【智能体平台、协议与执行系统】 【MCP】 【stateless】 【标准/生态影响】

📋 **要点**：2026年7月，**Model Context Protocol**（**MCP**）发布自推出以来最大的一次规范更新，核心变化是把 protocol core 从有状态改成无状态，使请求不再依赖单个 server instance 的会话状态。此次更新还加入了 **Multi Round-Trip Requests**、header-based routing、cacheable list results、authorization hardening、formal extensions framework 和更新后的 **Tier** 1 **SDKs**，目标是提升可靠性、可扩展性和企业部署适配度。
📌 **总结**：这次规范调整的实际价值在于，它把 **MCP** 从“本地连接模型和工具”的协议，推进为更接近企业级基础设施的请求/响应标准，降低了规模化部署时的状态管理、路由和安全接入难度。对技术路线来说，这意味着 agent 平台的关键瓶颈正在从能力演示转向企业可运维、可治理和可扩展；对生态而言，规范升级会直接影响工具提供方、**SDK** 维护者和平台型产品的接入设计。

原文标题：New MCP specification addresses the main barrier to enterprise adoption

### 1、Google联合高校用EnvHarness重塑训练环境并提升智能体迁移效率 {#event-31460}

【模型训练】 【EnvHarness】 【自适应训练环境】 【研发效率提升】

📋 **要点**：**Google Cloud** AI Research联合圣路易斯华盛顿大学和北卡罗来纳大学教堂山分校提出**EnvHarness**，针对静态智能体环境无法随策略能力变化继续提供有效训练的问题，在既有环境外增加仅通过reset和step接口工作的可编程包装层。EnvRigger从策略运行轨迹诊断系统性弱点并自动编写Stage、Contract和Chain组件，在不修改模拟器、任务及人工验证器的前提下改变起始状态、动作约束、观察内容或任务组合；五项基准上的迁移任务最高提升9.0分，**SWE-bench** Verified平均步骤减少**9.8%**。
